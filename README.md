# Накорми меня

Семейная головоломка «три в ряд»: собирай еду на доске и корми Дональда, Ростика и Алису.

**Играть:** https://sergey-0077.github.io/nakormi/

- iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- Android: открыть ссылку в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на гл. экран»).

Игра — один файл `index.html`, работает без интернета после первого запуска. Прогресс хранится на устройстве.
